# dotfiles

Personal configuration files, managed with git and symlinked into `$HOME`

## Installation

Clone this repository into the user directory and keep the folder name as `dotfiles`. The setup scripts expect these paths:

- **Windows:** C:\Users\<username>\dotfiles
- **macOS:** ~/dotfiles

```bash
cd ~
git clone https://github.com/ChaiyoKung/dotfiles.git
cd dotfiles
```
